An unknown chip is refused with the cause (plan item 3.11a)
===========================================================
16 November 2026, branch unknown-chip, built on 6.5.0. Not released.

WHY
---
6.5.0 reads any file with the four required columns and applies the Axiom numbers to it. On
Illumina HumanCytoSNP-12 (GSE60909) and Illumina 370k-class (GSE19247, GPL6985) it printed a
haploid stage on diploid cells, a "damaged sample" banner that came from the chip and not the
sample, ran on with an unrecognised genome build, and would drop an intensity column named
"Log R Ratio" in silence. Measured in audit/local/platforms-2026-11-16/report.txt (untracked).

THE RULE, written from the measurement below before the gate was scored
-------------------------------------------------------------------------
1. A file is the proven chip (UK Biobank Axiom) when at least half of its autosomal markers have
   an id the shipped founder panel holds. Otherwise it is not scored.
2. Autosomes only, because the panel holds no marker on X, Y or MT. A ratio of the rows present,
   so an export missing rows reads the same share as a whole one.
3. A refused file is named with every cause that can be named: the panel share; a genome build
   neither GRCh37 nor GRCh38 fits; an intensity or allele-fraction column that is absent, with the
   names looked for. A file whose header lacks a required column is refused with the names of the
   missing columns and the names looked for.
4. On the proven chip nothing changes. A missing intensity or allele-fraction column is named in
   the run log; an unrecognised build is named as before ("assembly undetermined").
5. The reader takes the intensity column under log2R, normalized_intensity, lrr, log_r_ratio,
   logrratio, "log r ratio", and the allele fraction under baf, b_allele_freq, "b allele freq",
   ballelefreq, b_allele_frequency, "b allele frequency", each also after a per-sample prefix
   ("GSM123.Log R Ratio"). Anything else is named as missing, never dropped in silence.
6. Without the panel (fetch failed) the chip is not checked and the run log says so.

holds, over every parsed row, then over autosomes. audit/local/platforms-2026-11-16/share.ts.

  Axiom, the 365 arrays behind the gate rows (laboratory series 235, GSE315671 55, GSE186407 37,
  GSE148488 35, three rebuilt fathers):
    all rows: 0.9737 on every one of the 362 measured arrays (825,656 rows each); 1.0000 on the

    autosomes: 1.0000 on all 365.
    the first 10% and the first 1% of rows: 1.0000; every 50th row: 0.9737.

  Illumina HumanCytoSNP-12 (GSE60909), 29 arrays (21 cells, 8 parents): 0.0000; 298,563 rows,

    342,887 outside GRCh37, 1,988 outside GRCh38).

THE BAR. Axiom 1.0000 on autosomes, the outside chips 0.0000, nothing between. The bar is 0.5,
half way: no Axiom file comes within 0.5 of it and no outside file within 0.5 of it.
A TRUNCATED AXIOM EXPORT. The share is per row present and every Axiom autosomal marker is in
the panel, so any subset of an Axiom export's autosomal rows reads 1.0000 and is scored. Only an
export with no autosomal row at all (X, Y or MT only) is refused, with the cause "it has no
markers on chromosomes 1 to 22". A third chip that shares some Axiom probeset ids would need more
than half of its autosomal markers to carry Axiom ids to pass; none is known.

DRAFT CHANGELOG PARAGRAPH (for the release that ships this; not in CHANGELOG.md)
--------------------------------------------------------------------------------
**A file from another chip is refused, with the reason.** The tool is proven on one chip, the UK
Biobank Axiom array, and until now it applied that chip's numbers to any file with the right
columns, printing a haploid stage and a damaged-sample banner on Illumina arrays that said nothing
about the sample. A file is now scored only when at least half of its autosomal markers are in the
founder panel: every Axiom file read measures 100% (365 arrays), the two Illumina series measured
0% (68 arrays). Any other file is not scored, and the page says so with each cause it can name:
how many of its markers the panel holds, a genome build neither GRCh37 nor GRCh38 fits, a missing
intensity or allele-fraction column. The reader now also takes those two columns under Illumina's
names ("Log R Ratio", "B Allele Freq", with or without a per-sample prefix) and names either one
as missing when it is absent, rather than dropping it. On Axiom nothing changes: all 600 records
of the truth set's with-parent and no-parent rows are identical.
